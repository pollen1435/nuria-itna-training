💡 Hoe dit programma werkt

Elke dag bevat:

✓ Introductie — Context thema (B2/C1)
✓ Vocabulaire — 42 woorden (7 categorieën)
✓ Test — 20 vragen (FILL/ORDER/INTRUS/QCM)
✓ Reading — ~280 woorden + compréhension
✓ Rédaction — Vrij schrijven met 3 verplichte woorden
✓ Feedback — Score + motivatie

Doel: Nuria bereikt minimaal 56% ITNA B2 (van 51% → 56%+ = +5 punten). Focus op vocabulaire familiariteit, nominalisaties, en B2-specifieke contexten.
